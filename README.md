# Rishwan K — Next.js & Full-Stack AI Systems Portfolio

Personal 3D interactive engineering portfolio of **Rishwan K** — Full Stack & AI Systems Engineer (2.5+ years experience) at **Centelon Solutions Private Limited** & **LevelX Learning LLP**.

## 🌟 Tech Stack & Architecture
- **Core Frameworks**: Next.js 15 (App Router, Server Actions, RSC, SSR), React 19, TypeScript
- **3D & Graphics**: Three.js WebGL Core with interactive touch swipe and gyroscope tilt
- **Styling**: Vanilla CSS with glassmorphism, responsive mobile-first architecture
- **AI & Intelligent Systems**: Model Context Protocol (MCP), Retrieval-Augmented Generation (RAG), LLM Integrations
- **Backend & Real-Time**: Node.js, Express.js, WebSockets, Web Audio API Synthesizer
- **Databases**: MongoDB, PostgreSQL, SQLite (Offline-First POS)

## 🚀 Key Features
1. **Interactive 3D WebGL Neural Core**: Custom Three.js polyhedron with mouse parallax and mobile swipe controls.
2. **Robotic Store Automation & AI Media Studio**: Live interactive simulation featuring real browser Speech Synthesis (TTS), store chime audio, playlist ducking, and AI video reel generation.
3. **Next.js 15 Architecture Deep Dive**: Interactive explorer for React Server Components, Server Actions, Streaming SSR, and Edge Runtime.
4. **Custom Build Scope Calculator**: Dynamic project blueprint generator with direct WhatsApp proposal trigger (`+91 7994776519`).
